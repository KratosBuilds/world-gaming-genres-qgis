# world-gaming-genres-qgis 🌍 
A QGIS project mapping the most popular video game genres across world regions.

## Overview
This project visualizes the most popular video game genres across major world regions using QGIS. I created a custom dataset linking each region to its dominant game genre, joined it with a world regions shapefile, and styled the results using categorized symbology. The goal is to produce a clear, global map that highlights regional gaming preferences in an accessible and visually appealing way.

## Data Sources
- **World Regions:** Natural Earth – *Admin 0 – Regions*
- **Game Genres:** Custom CSV created for this project

## Workflow Summary
1. Loaded Natural Earth world regions into QGIS.
2. Created and imported a custom CSV containing regions and their top game genres.
3. Performed an attribute join using the region name field.
4. Applied categorized symbology to visualize genre popularity.
5. Added labels, legend, and map layout elements.
6. Exported the final map as a PNG.
